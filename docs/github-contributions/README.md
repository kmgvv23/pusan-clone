## 보관 범위

- 관련 PR 본문, 리뷰 제출, 코드 리뷰 댓글, PR 대화 댓글, 변경 파일과 커밋 목록, 패치, 원문 URL을 저장했습니다.
- 각 기록에는 원래 작성자와 시각을 유지하며, 대화 맥락을 위해 다른 참여자의 댓글도 포함합니다.
- 원문 JSON도 함께 보관합니다. 첨부 이미지·외부 링크의 파일 자체, 삭제된 기록, 공개 API에서 볼 수 없는 기록은 이 보관본에 포함되지 않습니다.
- GitHub의 원래 PR·리뷰 이벤트로 재등록한 것이 아니라 파일 형태로 보관한 사본입니다.
- API 조회 시점의 스냅샷입니다. 원본에 이후 추가되는 기여는 자동 반영되지 않습니다.
